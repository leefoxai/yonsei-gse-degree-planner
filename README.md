# Yonsei GSE Degree Planner

연세대학교 교육대학원 졸업요건 이수현황과 향후 수강계획을 확인하기 위한 참고용 웹 도구입니다.

- 공개 버전: **v1.0.0**
- 데이터 기준학기: **2026-2**
- 제작자: **23-1 AI융합교육전공 이규호**
- 문의: **leefox@yonsei.ac.kr**

## 이용 안내

입력한 수강이력과 공개된 학사 기준을 바탕으로 자동 계산합니다. 최종 졸업 및 교원자격 취득 여부는 연세대학교 교육대학원의 공식 심사 결과를 따르며, 학점 인정·선수과목 인정·교원자격 관련 행정승인 등은 계산 결과와 다를 수 있습니다.

## 데이터 처리

선택한 성적정보, PDF 및 캡처 파일은 별도 애플리케이션 서버로 업로드하거나 저장하도록 구현되어 있지 않습니다. 분석과 계산은 브라우저에서 수행하며, 등록한 수강이력과 수강계획은 사용 중인 브라우저 저장공간에 저장됩니다. 앱 실행에 필요한 라이브러리와 글꼴을 불러오기 위해 외부 CDN에 접속할 수 있습니다.

## 유지보수

공개 웹앱에는 관리자 수정 기능이나 관리자 인증정보를 포함하지 않습니다. 이 저장소의 공식 데이터와 소스 변경은 저장소 쓰기 권한을 가진 유지관리자가 GitHub를 통해 반영합니다. 외부 사용자는 공개된 소스를 열람하거나 제안할 수 있지만 이 저장소에 직접 푸시할 수 없습니다.
