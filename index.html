2기존 수강이력 입력 / 가져오기

수강이력을 한 과목 이상 등록하면 아래 이수현황 분석이 자동으로 시작됩니다.
과거에 이수한 과목은 최신 개설표에서 사라져도 계산에 반영됩니다.
전공교직 과목은 교직 ↔ 전공선택으로 종별을 바꿀 수 있습니다.
성적은 4.3 만점 기준 C−(1.7) 이상만 이수로 인정하며, 졸업요건 평점은 누적평점 3.00 이상입니다.

PDF 파일이 있는 경우 · 권장

모바일 학사포털에서는 성적표를 PDF로 직접 출력하기 어렵습니다. 카카오톡·메일 등으로 받은 전체성적조회 PDF를 휴대폰에 저장한 뒤 불러오세요.

iPhone: PDF 열기 → 공유 → 파일에 저장 → 파일 앱의 다운로드·iCloud Drive·나의 iPhone에서 선택

Android: PDF 다운로드 → 다운로드/내 파일에 저장 → 저장된 PDF 선택

PDF 파일이 없는 경우

연세포털의 전체성적조회 화면을 여러 장 캡처한 뒤 한 번에 선택하세요. 학정번호·과목명·학점·성적이 잘리지 않도록 캡처하고, OCR 결과의 수강학기와 성적을 반드시 확인하세요.

가능하면 PDF 불러오기를 우선 권장합니다. OCR은 화면 캡처 상태에 따라 인식 결과를 추가 확인해야 합니다.
연세포털서비스 열기 ↗ 로그인 → 학사정보시스템 → 성적 → 학생 → 전체성적조회 → 우측 [출력] → PDF로 저장

연세포털 성적조회 PDF 불러오기

연세포털 → 학사정보시스템 → 성적 → 학생 → 전체성적조회 → 우측 [출력] → PDF로 저장한 파일을 불러오세요. 한 파일로 전체 학기를 가져옵니다.
권장
PDF 원본은 서버에 저장하지 않습니다. 브라우저에서 교과목 정보만 읽고, 등록한 수강이력만 로컬 저장합니다.
PDF 분석 기능은 버튼을 누를 때 필요한 라이브러리만 불러옵니다.
PDF를 선택하면 전체 학기 수강내역을 한 번에 가져올 수 있습니다.

캡처 여러 장 OCR

성적 화면 캡처를 여러 장 한 번에 선택하거나 차례로 붙여넣을 수 있습니다. 각 캡처의 수강학기를 확인한 뒤 한 번에 분석합니다.
PDF가 없을 때
여러 장 선택 · Ctrl+V 추가 지원
PC: 여러 이미지 파일을 한 번에 선택하거나, 캡처(Win+Shift+S) 후 이 영역에서 Ctrl+V를 반복하면 목록에 계속 추가됩니다.
작은 글씨는 자동 확대·명암 보정 후 인식하며, 인식이 약한 이미지는 더 크게 보정해 한 번 더 분석합니다.
학정번호·성적이 잘리지 않은 캡처가 가장 정확합니다. 서로 다른 학기 캡처를 함께 올린 경우 이미지별 수강학기를 수정할 수 있습니다.
캡처를 여러 장 선택하거나 하나씩 붙여넣으세요.
